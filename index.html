ISA Countdown

The ISA Countdown project, is something I came up with, in order to know when an event, such as a school break is going to happen, or an event such as a term is going to end. In other words, counting down to it.
Došeni

Došeni is a project, which acts as a family tree. This project was created to digitalize the family tree of the Došen family. It is made this way, so that it is sharable online, and preserved for a long time.

Janko Cafe

Janko Cafe is an online site, which basically a digital menu, for Janko Cafe. It was created, so that our menu is available to all costumers, and so that we save paper! Currently, the site only supports menu viewing. Online ordering isn't available.
